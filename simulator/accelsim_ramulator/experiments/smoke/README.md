# Smoke Experiments

This directory will hold the smallest reproducible Accel-Sim + Ramulator tests.

Initial smoke target:

1. Run Accel-Sim with the normal DRAM model.
2. Run Accel-Sim with a fixed-latency external memory backend.
3. Run Accel-Sim with the Ramulator HBM4 backend.
4. Compare completion counts and basic timing sanity.
